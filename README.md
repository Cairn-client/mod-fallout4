# F4MP (Fallout 4 Multiplayer) on Cairn

A fork of [saywhy2me/Fallout4Multiplayer](https://github.com/saywhy2me/Fallout4Multiplayer), the multiplayer mod for **Fallout 4**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the mod is published as a pack the launcher installs and updates, and Play starts the game through F4SE.
- A setup program for the launcher: it checks the game version (1.10.163), installs F4SE, switches the plugin on and enables loose files.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Open Fallout 4 in the Library, download the mod and press Play.

Experimental. It needs Fallout 4 on version 1.10.163.

Each release of this repository is the pack the launcher downloads.
